# Brand logos

Put official brand logo files here (SVG preferred, from each brand's press/media kit), e.g.

    toyota.svg  lexus.svg  honda.svg  nissan.svg
    mercedes-benz.svg  bmw.svg  land-rover.svg  hyundai.svg

Then set `logo: "/brands/<file>"` for that brand in `lib/data/brands.js`.
Until a logo is set, the site shows a neutral monogram badge in the same size.
